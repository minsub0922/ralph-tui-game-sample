## pure-renderer — 완료
src/ui/render.ts 에 renderFrame(state, viewport) -> string[] 순수 함수를 만들었다.
- 타입: Viewport { width, height }, RenderState { game, difficulty, highScore, isNewRecord }.
  최고 기록과 신기록 여부는 코어 상태가 아니라 저장소(다음 task)에서 오므로 GameState 와 분리해 따로 받는다.
  덕분에 render.ts 는 파일시스템을 몰라도 HUD 와 게임 오버 패널을 그린다.
- 화면 구성: 0행 HUD(` NORMAL  SCORE 00000  HI 00128`, 자릿수 고정 5자리라 매 tick 폭이 흔들리지 않는다),
  1행~height-2행 본문, height-1행 지면('=' 반복). 공룡의 발은 지면 바로 윗줄(height-2)에 선다.
- 좌표 변환: 세계는 위로 갈수록 y 가 커지고 화면은 위로 갈수록 행이 작아지므로 row = groundRow - round(y - groundY).
  열은 round(obstacle.x). 스프라이트는 히트박스와 같은 크기다 — 공룡 2x3 ['-@','##','/\'], 선인장 2x2 ['\|',' |'].
- 잘림: 문자 단위 grid 에 쓰고 setCell 이 화면 밖 좌표를 조용히 버린다. 그래서 x=-1000 이든 x=1000 이든
  예외 없이 부분 렌더되고, 반환은 언제나 height 줄 x width 글자다(0x0, 1x1 같은 퇴화한 크기 포함).
  스프라이트는 0행(HUD)을 덮지 않도록 BODY_TOP_ROW 아래만 그린다.
- gameOver: 가운데 정렬 ASCII 박스를 화면 중앙에 덮어 그린다 (GAME OVER / SCORE / BEST / * NEW RECORD * /
  R = RETRY   Q = QUIT). 신기록이 아니면 그 줄만 비워 박스 크기가 바뀌지 않는다.
